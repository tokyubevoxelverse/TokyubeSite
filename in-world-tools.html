In World Tools

Once you're inside a world, everything runs on modes — press M to cycle what your click does, tap C to change your camera, and hold C for the full Blender-style Build Camera. This page documents the real controls as they ship in the current build.

Overview

TokyubeVoxelVerse doesn't have separate editor apps: one world, one avatar, six modes. The active mode changes what your left click does — relax, mine, build, script, edit components, or place advanced FBX models. The in-game CONTROLS overlay (on the title screen and pause menu) always shows the current bindings.

Camera Views

Tap C to cycle through the four camera views:

  1. 1st Person — the default.
  2. 3rd Person Back — camera behind your avatar.
  3. 3rd Person Front — camera facing your avatar (great for posing skins, wigz and capes).
  4. 2D Side — a side-scroller style view.

In multiplayer, your voice-level mic indicator pill is visible above your head in the 3rd-person and 2D views.

Build Camera Mode (hold C)

Hold C to toggle the Build Camera — a Unity/Blender-style orbit editor for precision work (not available in public discovery worlds):

  • Drag — orbit around the focused item (selected FBX tree, mesh branch, or component).
  • Right drag — grab / pan the camera focus (the GRAB button toggles this onto left-drag too).
  • Scroll — zoom; the yellow ZOOM button sets a ×1–×50 speed multiplier.
  • Double-tap Z — zoom into the focused item (Unity "F" style); double-tap again to zoom back out.
  • Align views — Top / Bottom / Front / Back / Left / Right buttons, plus Grab / Rotate / Reset, in the panel's top-right.
  • Move / scale / rotate tools — click-to-select FBX trees, mesh branches and components, with constant-size gizmos and a 50-step undo/redo (Ctrl+Z / Ctrl+Y).
M is disabled while the Build Camera is active — hold C to leave the mode first.

The Mode Cycle (M)

Press M to cycle: Relaxed → Mine → Build → Script → Component → Advanced Building.

  • Relaxed — explore freely; no combat, clicks don't edit the world. Multiplayer guests in non-collab sessions and all public discovery worlds are locked to Relaxed.
  • Mine — left-click (hold) breaks blocks.
  • Build — left-click places the selected hotbar block.
  • Script — attach and run Tokyube Code Blocks on entities.
  • Component — add and edit world components and their properties.
  • Advanced Building — import and place FBX models, apply materials, and transform advanced objects.

TokyNode placement is its own mode entered from the TokyPhone's TokyNodes app — it's not part of the M cycle; press M to exit back to Relaxed.

Mine & Build Modes

Mining is continuous — hold left-click and sweep across blocks. Building places the currently selected hotbar item where you're aiming. Blocks support colored variants and per-voxel material overrides (see Per-Voxel Materials).

World types matter here: Blank World starts with no terrain at all — just a build grid — and supports full mine/build/component/FBX/script placement on empty space.

Hotbar & Inventory

The bottom of the screen shows the 10-slot hotbar; the full inventory is 50 slots (10 hotbar + 40 backing). Press Tab to open the inventory & save panel, number keys 1–0 jump to a hotbar slot, and the scroll wheel cycles slots.

Script Mode

In Script Mode your click selects entities to attach Code Blocks scripts to. The Blockly workspace opens with the full toolbox — organized into FBX / Component / Logic / Math / Variables categories with world-picker dropdown blocks — plus the Saved Scripts Library with 17 starter scripts. Scripts persist with the world.

Component Mode

Components are the engine's built-in interactive objects — TVs, mirrors, browsers, NPCs, particle FX, triggers, spawn points and more (27 ship with the game). In Component Mode you place them, select them, and edit their properties; drag arrows and light anchors make positioning precise. Every component is documented on the World Components page.

Advanced Building Mode

The FBX-scale toolset: import .FBX / .OBJ (with .MTL) / .TGA textured models into your world, walk inside them with true per-mesh collision, edit per-mesh with Unity-style move/scale gizmos, re-parent via hierarchy drag-and-drop, and apply PBR materials from the material library. Advanced Building pairs with the Build Camera for precision editing, and .blend files can be imported through the Blend Import component (baked to glTF by headless Blender with a live progress indicator).

TokyNode Mode

Place your cross-world saved objects anywhere. Opened from the TokyPhone's TokyNodes app; see the TokyNodes documentation for families, persistence and networking.

Per-Voxel Materials

Individual voxels can carry material overrides — colors and material properties beyond the base block type. Live material editing applies changes as you tweak them, and the global material library holds up to 750 materials.

Interacting (E & F)

E interacts with the world — picking up items and opening in-world panels like the YouTube search or web browser components. F is the play key at card tables and machines: Countdown, Solitaire, Blackjack and Slots (press again to close). The Card Crazy Lounge discovery world adds multiplayer UNO, Rummy and Gin Rummy with CPU modes.

Controller & Steam Deck

Full gamepad support via the browser Gamepad API with the standard layout — Xbox, DualSense (including Bluetooth), and Steam Deck all work, including in menus and the TokyPhone. The Controller Mapper overlay lets you remap every button. On Steam, the game uses the Generic Gamepad template rather than Steam Input, so pads behave the same in and out of Steam.

External Logins

Tokyube integrates six external services, each with its own sign-in on the title screen:

  • Steam — automatic when launched through Steam; powers multiplayer lobbies, friends and account identity.
  • Discord — account linking plus Discord Rich Presence.
  • Google and YouTube — sign in for YouTube-connected features.
  • Epic and Xbox — account linking.

Debug & Load Character

The Debug app on the TokyPhone bundles the developer helpers — load a TokyTar Stylizer character folder onto your avatar (animated folders auto-detect their frames), respawn, adjust time of day, and inspect performance stats. The in-world DEBUG toggle shows live coordinates and the day/night readout.
